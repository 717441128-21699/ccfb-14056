# 光学动捕标记点数据清洗工具

纯 TypeScript 实现的光学动捕(motion capture)数据清洗 Web 工具。核心算法与渲染解耦,
可在浏览器与 Node(测试/基准)双端运行,三维预览基于原生 WebGL2(无第三方图形依赖)。

## 能力

- **丢点检测**:扫描 `observed` 掩码,输出每个标记点的连续空档区间。
- **自动补点**:
  - *刚体补点*(高精度):对每个刚体做 3+ 点 Kabsch 配准(双侧 Jacobi SVD,
    对共面标记点与绕主轴旋转稳健),由刚体位姿预测丢失标记点;
  - *时间先验补点*:观测点不足时沿用邻近可靠位姿(低置信,单独标记);
  - *轨迹补点*:向心 Catmull-Rom 三次插值兜底长档,按真实帧号参数化、抑制过冲。
- **标签互换识别**:逐帧恒速轨迹预测 + 成对交叉距离判定,支持跨刚体与连续互换,
  输出互换事件并交换回正确标签。
- **骨骼解算**:刚体位姿 → 关节世界位姿 → 局部旋转的完整 FK 链路。
- **足部锁定**:接触检测(高度 + 水平速度)+ 两骨 IK,接触帧脚踝钉住不打滑。
- **穿模检测**:非相邻骨段胶囊体相交检测,输出穿透深度与问题帧。
- **身材重定向**:方向保持 + 目标骨长重建 + 接触点 IK,可套到不同体型角色。
- **WebGL2 预览**:实例化球体标记点、骨段线段、穿模/锁定标注、轨道相机与时间轴。
- **导入/导出**:自描述 JSON 与通用 CSV(表头 `frame,x_<marker>,y_<marker>,z_<marker>`)。

## 验收指标(见 `bench/run-bench.ts`)

- 一万帧完整清洗 **3.5 秒**(门槛 30 秒),约 0.35 ms/帧;
- 高置信刚体补点 **RMS 1.7 mm**(门槛 2 mm),最大误差约 7 mm;
- 长档轨迹/先验兜底受物理信息限制,单独统计、不纳入刚体精度口径。

## 目录结构

```
src/core/   纯 TS 算法层(无 DOM 依赖)
  math.ts       3D 数学 + 双侧 SVD Kabsch + 刚体配准
  rig.ts        21 关节骨架、15 刚体、60 标记点布局与身材参数
  motion.ts     走/跑/跳程序化动作、FK 反算、噪声/丢点/互换污染
  gap.ts        空档检测
  relabel.ts    标签互换检测与修复
  fillGaps.ts   刚体/先验/轨迹三级补点
  solve.ts      标记点 → 骨骼解算
  footlock.ts   足部接触锁定 + 两骨 IK
  penetration.ts 穿模胶囊检测
  retarget.ts   身材重定向
  pipeline.ts   管线总装与分阶段计时
  io.ts         CSV / JSON 序列化
src/ui/     WebGL2 渲染与界面
test/       Node 自动化测试(33 项)
bench/      一万帧性能与精度基准
```

## 命令

```bash
npm test       # 运行 33 项自动化测试
npm run bench  # 一万帧性能/精度基准
npm run dev    # 启动 Web 开发服务器
npm run build  # 类型检查 + 生产构建到 dist/
```

## 补点方法标注(`FillMethod`)

| 值 | 方法 | 含义 |
|----|------|------|
| 0 | Observed | 原始观测,未修改 |
| 1 | RigidBody | 3+ 原始点刚体配准,亚厘米精度 |
| 2 | Trajectory | 轨迹三次插值(长档兜底) |
| 3 | Prior | 刚体时间先验(观测不足,低置信) |

## 数据模型说明

标记点坐标以扁平 `Float32Array(F*M*3)` 存储,丢点位置写 `NaN` 且 `observed=0`;
刚体局部坐标以其驱动关节为原点,保证 `marker = jointPos + R_joint * local` 的
刚体关系在合成与解算两侧严格一致(干净数据配准残差 < 0.001 mm)。
